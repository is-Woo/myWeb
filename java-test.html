📝 [문제] 동적 정수 배열 (MyDynamicArray) 구현하기

기본 배열 크기를 2로 시작하여, 저장 공간이 부족해질 때마다 배열의 크기를 2배로 자동으로 확장하는 MyDynamicArray 클래스를 작성하세요.

📌 필드:

  • int[] array: 데이터를 저장할 기본 배열
  • int size: 현재 저장된 데이터 개수

📌 생성자:

  • 기본 생성자: 초기 크기가 2인 배열을 생성합니다.

📌 메서드:

  • void add(int element): 배열의 끝에 새로운 값을 추가합니다. 배열이 가득 찼다면 배열의 크기를 기존의 2배로 확장한 뒤 값을 저장합니다.
  • int get(int index): 지정한 인덱스의 값을 반환합니다. (인덱스가 유효하지 않으면 예외 출력)
  • int size(): 현재 저장된 데이터 개수를 반환합니다.
  • int capacity(): 현재 배열의 전체 용량(크기)을 반환합니다.
  • void printAll(): 현재 저장된 모든 데이터를 출력합니다.
